# JobTrack approved icon

**Selected: A — J-Track.** See [SELECTED.md](SELECTED.md).

The approved source family remains in `a-j-track/`. Original geometry uses a near-white continuous J and one mint progress milestone on a navy rounded tile. No fonts, filters or gradients are embedded.

Phase 6A promotes the original assets to `branding/jobtrack.ico`, `branding/jobtrack-256.png`, `public/images/jobtrack-logo.svg` and `src/app/favicon.ico`. The ICO is copied intact, retaining 16, 24, 32, 48, 64, 128 and 256px frames. The 16px and 32px source SVGs contain optical adjustments; larger sizes use the 512-unit master.

At native 16/32px sizes, the J remains open and the single coloured milestone stays visible on light and dark backgrounds. Original PNG edges use normal antialiasing. Rejected B/C files and proposal-only comparison/gallery/generation utilities have been removed after selection; no application build refers to them.

See [DATA_MIGRATION.md](../../DATA_MIGRATION.md) for current branding, runtime and upgrade notes. The repository MIT license and original copyright notice remain unchanged.
